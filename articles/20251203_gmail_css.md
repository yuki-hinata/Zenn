## 発覚した背景
弊社はオンライン家庭教師と生徒様とのマッチングプラットフォームを運営しております。新規の先生を紹介するために週に1度、HTMLメールを送信しております。そちらのメールに新規で項目を足すことになったため、リリース後の本番環境での動作確認をしていたところGmailで見たときのみ、メールのデザインが大きく崩れてしまっていることがわかりました。

起こっていたこと

デザインが崩れていた原因は、大きく分けて次の2つでした。

CSS の設定方法が間違っていた

Gmail でサポートされていない CSS を使用していた

それぞれ詳しく見ていきます。

1. CSS の設定方法が間違っていた

今回のメールでは、「先生カード」「コースカード」といった UI コンポーネントを複数箇所で使い回す必要がありました。
将来的にも再利用する場面が増えそうだったため、Laravel Blade のコンポーネント機能を使って x-mail.teacher-card や x-mail.course-card といったコンポーネントに切り出していました。

```
@foreach($teacher['courses'] as $course)
  <div class="course-card-container">
    <x-mail.course-card :course="$course" />
  </div>
@endforeach
```

当初は、この コンポーネントの内部で <style> タグを使って CSS を定義 していました。
しかし、Blade コンポーネントはメール本文側に展開されるため、実質的に「body 内で <style> を書いていた」状態になっており、Gmail 上ではその CSS がすべて効いていない、というのが崩れの原因の1つでした。

解決策：レイアウトにスタイルを集約し、Blade から読み込む

毎回コンポーネントを使うたびに <style> をコピペするのは現実的ではないため、次のような形に整理しました。

メール専用の Blade レイアウトを用意する（例：resources/views/layouts/teacher-card-and-course.blade.php）

そのレイアウトの <head> 内に、コンポーネント用の CSS をまとめて定義する

各メールテンプレートでは、そのレイアウトを @extends し、本文だけを定義する

イメージとしてはこんな構成です：

```
{{-- layouts/teacher-card-and-course.blade.php --}}
<html>
  <head>
    <meta charset="utf-8" />
    <style>
      /* teacher-card / course-card など、メール全体で使うスタイル */
    </style>
  </head>
  <body>
    @yield('content')
  </body>
</html>
```

```
{{-- mails/new-teachers.blade.php --}}
@extends('layouts.mail')

@section('content')
  {{-- ここで x-mail.course-card コンポーネントを使う --}}
  @foreach($teacher['courses'] as $course)
    <div class="course-card-container">
      <x-mail.course-card :course="$course" />
    </div>
  @endforeach
@endsection
```

こうすることで、

CSS は必ず head 内に出力される

各メールテンプレート側では、Blade コンポーネントを呼び出すだけでレイアウト崩れなく使い回せる

という状態になり、Gmail 上でも意図したデザインで表示されるようになりました。

2. Gmail でサポートしていない CSS を使用していた

もう1つの問題は、Gmail がそもそもサポートしていない CSS プロパティを多用していた ことです。

Gmail には「使える CSS / 使えない CSS」が公式にまとめられており、サポートされている CSS 一覧
を見ると、よく使うプロパティの中にもサポート外のものがいくつかあります。

今回のテンプレートで特に影響が大きかったのは次の3つでした。
1. position
2. flex-wrap
3. align-items

普段のフロント開発だと
- `display: flex`と`align-items: center`で中央寄せ
- `flex-wrap: wrap`で収まりきらない要素を折り返し
などのレイアウトを組むことが多いです。

ですが、Gmailで表示するとこれらがサポート外になっているため、以下のようなことが起こりました。
- 中央寄せにしたかったものが微妙にズレている
- 折り返しが入らないので、不自然な見た目になる

解決策：テーブルレイアウトや「昔ながらの」CSS に置き換える
そこで、メールテンプレートでは割り切って、

- `display: table`と`display: table-cell`を使用する

- 縦中央揃えは `vertical-align: middle` 使用する

といった、いわゆる「昔ながらの HTML メールの作り方」に寄せる形で調整しました。
